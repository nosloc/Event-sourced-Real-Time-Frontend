# Event-sourced real-time frontends

Code from a Master's thesis project (EPFL) on event-sourced, real-time frontends,
written in Scala 3 (Scala.js + Laminar on the browser side, http4s on the JVM).

Work in progress.

- `code/prototype`: a small full-stack prototype.
- `code/laminar-playground`: learning exercises with Scala.js and Laminar.
